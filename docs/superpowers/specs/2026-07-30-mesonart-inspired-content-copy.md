# YiiArt Content & Copy Spec — MesonArt-Adjacent（Sprint 0）

> 用途：生成**接近 MesonArt 转化语气**、但属于 YiiArt 的原创文案、评价与图片内容  
> 原则：**结构可接近，原文/原图不可复制**  
> 默认销售语言：English；中文为平行翻译，不直译营销腔

## 1. 品牌声线

| 维度 | YiiArt 应有的感觉 |
|------|-------------------|
| 语气 | 冷静、具体、帮买家做决定；不夸张「改变人生」 |

## 3. 商品描述生成模板

### 3.1 About the Artwork（1 段）

英文模板：

```text
A {orientation} canvas defined by {color_palette} and {composition_movement},
bringing {mood} to {room_fit}. {texture_note} keeps the surface alive, while
the {style} language stays versatile for {interior_style} interiors.
```

示例（原创）：

> A square canvas defined by deep charcoal and warm metallic gold, bringing focused energy to modern living rooms. Raised plaster texture keeps the surface alive, while the abstract language stays versatile for Art Deco and contemporary interiors.

### 3.2 标题命名

- 格式：`{Poetic Name} #{SKU}`  
- 例：`Gilded Quiet Field #YA204`  
- SEO 标题可另写：`Black and Gold Textured Abstract Canvas for Modern Living Rooms | YiiArt`

### 3.3 Details 默认值（可按商品覆盖）

| Field | Default EN |
|-------|------------|
| Availability | Made to order, 100% hand-painted by a studio artist |
| Creation time | 1–2 weeks |
| Ready to hang | Yes (when stretched / framed options selected) |
| Frame | Multiple frame finishes available |
| Authenticity | Certificate included |
| Signature | Signed on the back by default |
| Customization | Custom sizes and colour direction available |
| Outdoor safe | No |
| Delivery cost | Shipping included in price for most destinations* |
| Delivery time | Typically 5–10 business days after dispatch |
| Returns | 30-day return policy — see Shipping & Returns |
| Carrier | DHL / UPS / FedEx (route dependent) |
| Area | Worldwide where carriers allow |

## 4. 评价（Reviews）生成规范

### 4.1 允许生成什么

- **演示/占位评价**：用于设计预览、空状态、营销区块 mock  
- **上线真实评价**：优先真实买家；若用生成内容，必须可切换/标注，且符合平台诚信政策  

### 4.2 评价数据结构

```ts
type GeneratedReview = {
  id: string
  authorName: string          // 名 + 姓首字母，如 "Ava M."
  rating: 4 | 5               // 以 5 星为主，偶发 4
  title: string               // 短标题 4–8 词
  body: string                // 40–90 词
  createdAt: string           // ISO date
  location?: string           // "Austin, US"
  productSku?: string
  productTitle?: string
  verifiedPurchase: boolean
  photos: Array<{
    role: "room" | "detail" | "unboxing"
    prompt: string            // 生成图提示词
    alt: string
  }>
  highlights?: Array<"quality" | "shipping" | "size-help" | "colour-match">
}
```

### 4.3 评价文案模板（接近电商语气，原创）

**类型 A — 上墙效果**

> Title: Looks larger in person  
> Body: We ordered the 40×54 for our dining wall and the scale feels right — not overwhelming. The texture reads beautifully in afternoon light. Packaging was solid and the canvas arrived ready to hang.

**类型 B — 配色**

> Title: Colour matched our sofa better than expected  
> Body: I sent a room photo and the studio suggested a slightly warmer beige. Glad we asked. Brushwork feels handmade, which is what we wanted versus a print.

**类型 C — 物流/服务**

> Title: Clear updates, careful crate  
> Body: Took about ten days door to door. The team answered size questions quickly. Corner protection was excellent; no pressure marks on the surface.

**类型 D — 定制**

> Title: Custom size for a narrow hallway  
> Body: Needed a panoramic piece for a tight corridor. They confirmed proportions before painting. It feels intentional, not like a cropped version of a square work.

### 4.4 评价语气规则

- 具体：提房间类型、尺寸、光线、咨询过程  
- 可信：允许轻微保留（「比照片略深一点」）  
- 禁止：复制竞品评价；禁止虚假「律师/医生」身份；禁止医疗/投资暗示  
- 名字多样化；避免连续同名  
- 配图评价占比建议 40–60%（首页精选可更高）

### 4.5 批量生成 Prompt（给模型用）

```text
Write 8 original YiiArt customer reviews for hand-painted canvas art.
Tone: calm, specific, ecommerce-real (like premium art DTC sites).
Each review: author (First L.), 4–5 stars, short title, 50–80 word body,
optional city, 0–2 photo roles (room/detail/unboxing).
Do not mention MesonArt. Do not copy existing reviews.
Vary rooms: living, bedroom, office, entry. Mention size help or texture once each.
Output JSON matching GeneratedReview.
```

## 5. 图片内容生成规范

### 5.1 每件商品最低图组

| # | Role | 用途 |
|---|------|------|
| 1 | `product` | 白/纸色底，正面作品 |
| 2 | `room_hero` | 客厅/主场景上墙 |
| 3 | `detail` | 笔触/肌理特写 |
| 4 | `room_alt` | 第二场景（卧室/走廊） |
| 5 | `finish` | 可选：画框边缘或卷筒包装 |

### 5.2 场景图 Prompt 模板

```text
Photorealistic interior featuring the supplied artwork as a {W}" × {H}"
canvas on a {wall} wall in a {room}. Preserve artwork exactly, correct
aspect ratio and scale, {finish} treatment, {lighting}, slight angle,
natural shadow, high-end but lived-in styling, no watermark, no logo,
no extra text, no distortion.
```

参数建议：

- wall: warm plaster / soft limewash / quiet oak panel  
- room: modern living room / calm bedroom / gallery hallway  
- lighting: late-afternoon side light / soft north light  
- finish: frameless float / thin oak frame / rolled edge not visible on wall  

### 5.3 评价配图 Prompt

**room**

```text
Customer-style phone photo of a hand-painted canvas on a residential wall,
natural indoor light, slight perspective, realistic furniture edge in frame,
not a perfect catalog shot, no faces, no logos.
```

**detail**

```text
Close-up of acrylic/oil texture on canvas, visible brush ridges,
soft daylight, shallow depth of field, documentary feel.
```

**unboxing**

```text
Opened protective art crate/tube corner on a clean floor,
kraft paper and foam visible, artwork edge partly shown, realistic home setting.
```

### 5.4 法律与诚信披露（必须保留）

全站统一（已有披露可沿用）：

> Listing images illustrate the intended composition, palette, and room scale. Each canvas is hand-painted to order, so brushwork and small details will naturally vary.

评价图若为生成图：后台标记 `source: generated`；面向用户的精选区优先真实图。

## 7. 促销与紧迫感（慎用）

允许：

- 真实工作室档期：`Studio sale ends Sunday`  
- 真实库存/制作排期  

避免长期假倒计时。若做倒计时 UI，必须绑定真实 `saleEndsAt`。

社会证明：

- **已锁定**：先用占位文案展示 UI（如 `3 sold in the last 48 hours`），后续再接真实订单聚合  
- 生成评价：**已锁定可上正式站**（CMS 可策展；文案须 YiiArt 原创）  
- 促销倒计时：仅绑定真实 `saleEndsAt` 时显示
